# Kenya Safari 手册

行程地图、出行准备、动物观察，支持登录后跨设备共同编辑。

网址：https://mozhu621.github.io/kenya-safari/

## 开始共同规划

1. 打开网页右上角的云端面板，使用邮箱和至少 10 位密码创建账号。
2. 点“将当前手册创建为共享行程”。路线、晚数、时间设置、清单和备注会上传到该账号的私有行程。
3. 点“生成一次性邀请码”，私下发给同伴。同伴创建自己的账号后，粘贴邀请码加入。
4. 同一人换设备时，使用相同账号登录并选择行程。

联网时约每 5 秒同步。不同清单项可分别修改；同时修改同一路线或同一清单项时，会提示选择版本。已经打开的网页在断网时暂存修改，联网后重试。路线保留最近 20 个历史版本。

## 保存和隐私

- GitHub Pages 提供公开默认手册；登录后的修改存储在 Supabase，仅行程成员可读。
- 未登录时只在当前浏览器保存。旧本地 file:// 页面的修改不会自动迁移到新网址；请保留原页，通过更新后的本地手册创建共享行程，或先导出备份。
- “保存整本 HTML”会导出当前路线与清单，请只分享给希望看到这些内容的人。导出不包含登录凭据。
- 此公开源码只含 Supabase 公钥。数据访问由数据库权限、登录和成员关系控制。
- 免费 Supabase 项目可能因长时间不活跃暂停；管理员可在控制台恢复。不要把云端当成唯一备份，可定期导出 HTML。
