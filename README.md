# Kenya Safari 手册

地图、出行准备与动物观察，支持专属链接共同编辑，无需注册、登录或邀请码。

## 使用

- 打开主人分享的完整网址（包含 `#share=…`），会自动连接到同一份行程。
- 拿到该链接的人可以查看、修改和继续转发。公开首页不包含专属链接，不能凭首页地址读取共享数据。
- 联网时约每 5 秒同步路线、晚数、清单和备注；同一项同时修改时提示选择版本。打开中的页面断网后可暂存，联网后继续同步。
- “保存整本 HTML”导出独立离线备份，备份不自动连接或覆盖共享行程，也不包含共享链接。
- 原有本地文件的修改不会自动导入共享行程。

## 路线方案

地图页新增最短前三种、原行程倒序及均衡方案。穷举当前酒店的所有顺序，保留酒店集合和各酒店晚数；默认马赛马拉两家连续住。总时间沿用当前路网、预留、休息和手动车程口径；分段明细展示入住、离店日期。点击使用方案才会修改并同步共享路线，可撤销。模型时间不等于实时或司机确认车程。

## 技术与管理

GitHub Pages 托管页面，Supabase 保存共享文档与最近 20 个路线历史版本。专属链接使用随机 256 位令牌，数据库只存其哈希。表不开放匿名直接访问；RPC 校验链接权限和版本号后才能读写。令牌在网址 fragment 中，不发送给 GitHub Pages，也不写入公开源码。

网页更新：替换根目录 index.html 并提交。云端行程独立保存，发布网页不会重置数据。免费 Supabase 项目如因不活跃暂停，可从项目控制台恢复。
